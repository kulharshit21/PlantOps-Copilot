# Spindle Vibration SOP

Page 1

When CNC spindle vibration rises together with torque load and tool wear, stop the active job at the next safe pause. Inspect tool holder runout, spindle bearing noise, lubrication state, and tool clamping pressure.

Page 2

If vibration remains above the watch threshold after tool replacement, schedule bearing inspection before the next production shift. Create a high-priority work order and attach torque, vibration, and tool wear readings.
