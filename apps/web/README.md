# PlantOps Copilot Web

Next.js frontend for the PlantOps Copilot industrial AI command center.

## Scripts

```bash
npm install
npm run lint
npm run build
npm run dev
```

The Phase 1 UI is a polished landing/demo entry page. Later phases will add authenticated dashboards, asset registry, RAG chat, work-order review, security proof, and ops health pages.
